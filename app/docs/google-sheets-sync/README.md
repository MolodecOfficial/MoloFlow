# Двухсторонняя синхронизация MoloFlow ⇄ Google Таблицы без service account

Интеграция использует Google Apps Script, привязанный к вашей таблице. Не нужны `GOOGLE_SERVICE_ACCOUNT_JSON`, JSON-ключи, Google Cloud Project или ручная выдача доступа сервисному аккаунту.

## 1. Создать мост в Google

1. Откройте вашу таблицу: https://docs.google.com/spreadsheets/d/1CTE1Xx-NdiMon18iRfqBfzqZww-50dfMzZlTZj5d1e8/edit
2. Выберите **Расширения → Apps Script**.
3. Замените код редактора содержимым файла `Code.gs` из этого каталога и сохраните.
4. Нажмите **Развернуть → Новое развертывание**.
5. Тип: **Веб-приложение**. «Выполнять от имени»: **я**. Доступ: **Все** (или «Все пользователи», если так называется в интерфейсе).
6. Нажмите «Развернуть», пройдите авторизацию Google и скопируйте URL веб-приложения, заканчивающийся на `/exec`.

Важно: веб-приложение будет доступно по URL всем, кто его знает. Скрипт ограничен указанным ID таблицы, но запросы к ней не требуют отдельного входа. Не используйте этот мост для таблиц с секретными данными. Для чувствительных данных нужен OAuth с входом пользователя.

## 2. Настроить сервер MoloFlow

Добавьте **одну** переменную окружения на сервере, где работает Nuxt:

```env
GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/ВАШ_ID_РАЗВЕРТЫВАНИЯ/exec
```

Перезапустите сервер. Не добавляйте `GOOGLE_SERVICE_ACCOUNT_JSON`.

## 3. Использовать

В MoloFlow откройте MoloTable → кнопка облака → вставьте ссылку на Google Таблицу → «Проверить» → выберите вкладку и режим первичной привязки.

- **Объединить** — объединяет данные, при одновременном изменении одной ячейки приоритет у MoloTable.
- **Взять из Google** — копирует данные Google в локальный лист.
- **Отправить в Google** — локальный лист становится источником первичного заполнения Google.

После привязки локальные изменения отправляются с задержкой, а изменения в Google проверяются каждые 30 секунд. Удаление строк/столбцов и форматирование не синхронизируются — передаются значения ячеек.

## Ограничения

- Для работы требуется один раз опубликовать Apps Script и указать его URL в окружении сервера.
- Привязка листа работает по названию вкладки; не переименовывайте вкладку после подключения без перепривязки.
- Apps Script может возвращать ошибки при превышении квот Google.
